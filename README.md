# NO·HESI — Highway Rush

A small, browser-playable highway traffic runner inspired by No-Hesi driving.

## Play

Open `index.html` in a modern browser. No build step or dependencies are required.

- **W** — accelerate
- **A / D** — steer left / right
- **S** — brake
- **Esc** — pause or resume

Weave close to traffic for near-miss points and a temporary speed boost. Distance and near misses contribute to your score; each completed run awards credits based on distance and near misses. Spend credits in the garage to unlock and equip faster cars. Progress is saved in your browser's local storage.

Mobile users can use the on-screen controls.
